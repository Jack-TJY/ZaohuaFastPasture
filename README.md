# ZaohuaFastPasture 小世界加速

《造化仙缘》BepInEx 插件：加速造化鼎小世界里灵草、矿石和灵鱼的生长。

## 效果

- 灵草（灵田）和矿石（矿脉）的基础生长时间按品阶可调，单位天，默认是原版的一半。
- 灵泉/火炼池从原版的「每个 +100% 速度，多个相加」改为**相乘叠加**：每个相邻设施让生长时间减少一个百分比（默认 50%），挨 n 个设施时剩余时间 = (1 − 百分比)ⁿ。
- 灵鱼（灵池）按品阶缩短：生长时间 × (1 − 百分比)^阶，默认 50%（一阶 ×0.5，二阶 ×0.25，三阶 ×0.125，四阶 ×0.0625）。
- 灵泉、火炼池的说明文字同步改成新效果。

默认设置下，相对原版不挨设施的作物：

| 相邻设施 | 原版 | 本插件 |
| --- | --- | --- |
| 0 | 1× | 2× |
| 1 | 2× | 4× |
| 2 | 3× | 8× |
| 3 | 4× | 16× |
| 4 | 5× | 32× |

## 安装

需要先装好 BepInEx 5。把 `ZaohuaFastPasture.dll` 放进 `GodWorld\BepInEx\plugins\`。旧存档里已经种着的作物也会立刻按新倍率生长。

卸载：删掉 dll。已存档的作物保留加速后的数字，直到下次放置、移动建筑或播种时恢复原版。

## 配置

可以在 [ZaohuaModManager](https://github.com/Jack-TJY/ZaohuaModManager) 的「插件设置」页里直接改，改完立即生效；也可以改 `BepInEx\config\zaohua.fastpasture.cfg`。

| 分组 | 配置项 | 默认 | 含义 |
| --- | --- | --- | --- |
| 1 灵泉与火炼池（相乘叠加） | 每个设施缩短百分比 | 50 | 每个相邻设施让生长时间减少的百分比，0–95。多个相乘：剩余时间 = (1 − 该值%)^设施数 |
| 2 灵草与矿石基础生长时间（天） | 一阶下品 … 四阶上品 | 原版一半 | 每个品阶不挨设施时的生长天数，1 年 = 360 天 |
| 3 灵鱼 | 每阶缩短百分比 | 50 | 生长时间 × (1 − 该值%)^阶，0 = 原版 |

各品阶原版天数：

| 阶 | 下品 | 中品 | 上品 |
| --- | --- | --- | --- |
| 一阶 | 10 | 20 | 30 |
| 二阶 | 360 | 720 | 1080 |
| 三阶 | 3600 | 7200 | 10800 |
| 四阶 | 36000 | 72000 | 108000 |

## 原理

原版 `PastureImpl.RefreshPastureEffect` 每次都从零算出每块地的 `growTime` 和 `updateGrowSpeed`（灵泉/火炼池各 +100%，相加）。插件在它之后改写这两个值（灵草/矿石的 growTime 换成设置的天数；加速按「÷100 得设施个数」换算成相乘后的百分比），并在 `RefreshGrow` 前先重算一次，让旧存档立刻生效。

## 编译

把游戏 `Zaohua_Data\Managed` 里的 `Assembly-CSharp.dll`、`UnityEngine.dll`、`UnityEngine.CoreModule.dll` 和 `BepInEx\core` 里的 `BepInEx.dll`、`0Harmony.dll` 复制到 `lib\`，然后：

```
dotnet build src -c Release
dotnet run --project tests   # 离线核对倍率
```
